The Windows key is called **Super** on Ubuntu, and most of what you pressed it with on
Windows carries over: **Super + L** locks the screen, **Super + D** shows the desktop,
**Super + Left** and **Super + Right** snap a window to half the screen. A handful don't,
and those are the ones people search for.

Everything below is the default on both current LTS releases, Ubuntu 24.04 (GNOME 46) and
Ubuntu 26.04 (GNOME 50), in the standard Ubuntu desktop. The 26.04 defaults were read from
the installed settings schemas, and the 24.04 ones from GNOME's 46 schema files and
Ubuntu's 24.04 settings package; the two match for every shortcut in this table.

## The short answer

- **Win + Shift + S** (snip a region) → **Print**, the Print Screen key. It opens GNOME's
  screenshot tool.
- **Win + .** (emoji) → **Ctrl + .** or **Ctrl + ;** inside a text field of most apps.
- **Win + V** (clipboard history) → nothing. **Super + V** opens the notification list,
  because Ubuntu has no clipboard history. You add one, and you can put it on Super + V.
- **Win + E** (File Explorer) → nothing by default. One setting adds it.
- **Ctrl + Alt + Delete** → the log-out dialog, not a task manager.

## The three everyone asks about

### Win + Shift + S: the Print key

On Windows, Win + Shift + S lets you select a region of the screen and capture it to the
clipboard. On Ubuntu that is the **Print** key on its own. It opens a screenshot
tool where you drag a region, or pick the whole screen or a window, and capture.
{/* TEST + VERIFY (GNOME help): where the capture goes — clipboard and ~/Pictures/Screenshots — on 24.04 and 26.04. */}

Two more go straight to a file without the tool: **Shift + Print** takes the whole screen
and **Alt + Print** takes the active window. For video, **Ctrl + Shift + Alt + R** opens the
same tool in screen-recording mode.

### Win + . : the emoji panel

Windows opens its emoji panel with Win + . or Win + ;. On Ubuntu, apps built with GTK,
GNOME's own toolkit, open an emoji chooser with **Ctrl + .** or **Ctrl + ;** while you are
typing in a text field; GTK's documentation lists both as the default. Apps that aren't
built with GTK, browsers among them, may not have it.
{/* TEST: Ctrl + . in GNOME Text Editor, Firefox and Chrome, on 24.04 and 26.04. */}

Ubuntu's input-method framework, IBus, also binds **Super + .** to an emoji picker by
default, though whether it opens depends on your input-method setup.
{/* TEST: Super + . with the default English keyboard on 24.04 and 26.04. */}

When neither works, the **Characters** app (open the overview, type "characters") lets you
search for an emoji and copy it. Both 24.04 and 26.04 include it in the default install.

### Win + V: there is no clipboard history

Win + V opens Windows' clipboard history. Ubuntu has none, in 24.04 or 26.04, and
**Super + V** opens GNOME's notification list instead (so does **Super + M**). So this one
is two steps: install a clipboard history, then give it a shortcut.
[Win+V on Linux](/blog/win-v-clipboard-history-linux) has both: the one command that frees
Super + V without losing the notification shortcut, and a comparison of what you do and
don't get compared with Windows.

Clipmer is ours, so weigh this section accordingly. It is one of the options, and opens with
**Ctrl + Shift + D** until you move it to Super + V:

## Shortcuts with no equivalent, and how to add one

GNOME lets you bind any key combination to a command. Open **Settings → Keyboard → View and
Customize Shortcuts → Custom Shortcuts**, add one, give it a name, a command and a key.

For **Win + E**, GNOME also has a ready-made **Home folder** shortcut in the **Launchers**
group of the same settings page, unset by default; giving it a key does the same thing
without a custom command.
{/* TEST: the Launchers group and its Home folder entry, on both releases. */}

GNOME does not warn you when a key you pick from outside its Settings app collides with
one of its own, so if a new shortcut does nothing, check that list first.

## Shortcuts Ubuntu has that Windows doesn't

A few worth learning in your first week:

- **Ctrl + Alt + T** opens a terminal.
- **Super + Tab** switches between apps, while **Alt + Tab** switches between windows.
- **Super + H** hides the current window.
- **Super + A** opens the full app grid.
- **Super + Ctrl + 1 … 9** opens a *new* window of the nth dock app, rather than switching
  to the one that is open.

{/* TEST: each of these five on 24.04 and 26.04; Super + Ctrl + 1-9 was read from the 26.04 schema only. */}

[Ubuntu productivity tips](/blog/ubuntu-productivity-tips) goes further into the ones that
save the most time, including **Alt + `** between windows of the same app.

## When this table doesn't apply

- **Kubuntu or another KDE Plasma desktop.** Plasma has its own shortcuts, and some of
  them are much closer to Windows: **Meta + V**, for one, already opens a clipboard history.
  This table is for the GNOME desktop that standard Ubuntu ships.
- **You changed a shortcut, or an extension did.** The table lists defaults. Settings →
  Keyboard shows what yours are now.
- **A Mac-style keyboard or a laptop without a Print key.** The screenshot tool is also in
  the quick settings menu (**Super + S**).
